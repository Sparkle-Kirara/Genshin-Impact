Genshin Impact (Fan-made)

«Status: Alpha Prototype (Learning Project)»

About

This is a fan-made Genshin Impact-inspired project created for learning, research, and game development practice.

The primary goal of this project is not to recreate or redistribute Genshin Impact, but to study and implement core game systems such as:

- Combat System
- Character & Party System
- Inventory
- Quest System
- World Exploration
- UI / UX
- Save System
- Title Screen
- Mobile Controls
- Game Architecture

The project is developed using HTML, CSS, and Vanilla JavaScript.

About Assets

To respect the intellectual property of HoYoverse and other copyright holders:

- Official game assets are NOT included in this repository.

  - Music (OST)
